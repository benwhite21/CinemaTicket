# 🎬 CinemaTicket — Hệ thống Quản lý Bán Vé Xem Phim

## Công nghệ sử dụng
- ASP.NET Core 8.0 MVC (C#)
- Entity Framework Core 8.0
- SQL Server (LocalDB)
- ASP.NET Identity
- Bootstrap 5 + Custom Dark Theme
- Chart.js

## Tài khoản demo
- **Admin**: admin@cinema.com / Admin@123456
- **Customer**: test@cinema.com / Test@123456

## Chức năng chính
- Đặt vé xem phim online
- Chọn ghế ngồi trực quan
- Quản lý phim, lịch chiếu, rạp chiếu
- Admin Dashboard với biểu đồ doanh thu
- Thanh toán và xác nhận vé

## Cách chạy
1. Clone repo
2. Mở solution trong Visual Studio 2022
3. Chạy Update-Database
4. Ctrl + F5
